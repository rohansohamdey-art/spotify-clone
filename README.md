# 🎵 Spotify Clone

A responsive Spotify Clone built using HTML and CSS. This project recreates the basic user interface of Spotify to improve my frontend development skills.

## 🚀 Live Demo
🌐 https://rohansohamdey-art.github.io/spotify-clone/

## 💻 GitHub Repository
🔗 https://github.com/rohansohamdey-art/spotify-clone

## ✨ Features
- Responsive Spotify-inspired UI
- Sidebar Navigation
- Music Player Section
- Album & Playlist Cards
- Clean and Modern Design

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome
- Google Fonts
